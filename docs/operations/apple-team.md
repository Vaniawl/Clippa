# Робота з Apple-командою

Відкрий цей репозиторій у Codex і почни новий чат у його корені. Codex читає
`AGENTS.md`: головний агент працює координатором. Окремого перемикача чи контакту
для координатора немає. Назви спеціалістів пам’ятати не потрібно.

Приклади звернень:

- «Маю ідею фічі … Досліди й запропонуй один рекомендований варіант».
- «Продумай UX цього сценарію, включно з помилками та відновленням».
- «Реалізуй погоджений варіант; зроби незалежний review і необхідні перевірки».
- «Відтвори й виправ цей баг у межах описаного сценарію».
- «Підготуй позиціонування й матеріали для App Store».
- «Перевір готовність до релізу».

За замовчуванням `advise` повертає рекомендацію в чат без змін репозиторію.
Явний запит реалізації запускає `execute`: реалізацію, review, перевірки й
виправлення в погодженому обсязі. Зміна продуктового напрямку, розширення обсягу
й зовнішні дії погоджуються окремо; публікація та merge не виконуються автоматично.
Моделі успадковують налаштування користувача. Ліміт — три працівники й
координатор; нижчі обмеження середовища або проєкту мають пріоритет.

Продуктові рішення зберігаються в наявних PROJECT, vision, BACKLOG, ADR і handover.
Після відновлення сесії попроси: «Продовж погоджену роботу з останнього handover».
Координатор перевірить поточну ревізію перед продовженням.

Локальна перевірка конфігурації (Python 3.11+ і PyYAML):

```sh
python3 scripts/agent-framework/validate.py
python3 scripts/agent-framework/render.py --check
python3 scripts/agent-framework/check-team.py --json
```

`check-team.py` лише читає конфігурацію та доступні можливості. Генерація профілів
Codex, Claude, Kimi й OpenCode не доводить реальне виконання кожним провайдером.
Якщо host надає лише загальне делегування, координатор передає canonical role ID,
її інструкції, скіли й контракт через role adapter. Named-agent discovery і
доступність інструментів перевіряються окремо. Opt-in live smoke test описано в
`python3 scripts/agent-framework/smoke-team.py --help`; він потребує авторизованого
провайдера і може витрачати inference credits.

У цьому перенесенні native smoke для конкретного застосунку, manual accessibility
і runtime UI перевірки — `NOT RUN`. Код застосунку не змінюється. Наявні
налаштування й обмеження інших провайдерів залишаються чинними.
