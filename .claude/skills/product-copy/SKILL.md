# Product Copy

## Trigger and inputs
Use when UI labels, empty/error/recovery text, onboarding text or marketing messages need writing or review. Inputs: audience, product behavior, tone, existing terminology, character limits/locales and evidence supporting claims. This skill does not authorize adding onboarding or editing code.

## Output and method
Return a copy table identifying surface/state, intent, proposed text, action/recovery, length/localization constraints and evidence for factual promises. Tell users what happened and what they can do; preserve entered work where the UX permits. Prefer concrete verbs, distinguish destructive actions, and avoid blaming users or exposing implementation details. Reuse established vocabulary. Check long strings, pluralization, locale formats and screen-reader clarity; supply realistic overflow examples instead of assuming English length.

For marketing, map each capability/benefit promise to verified behavior or evidence. Replace unsupported superlatives, guarantees and fabricated customer quotes with defensible wording. Simulated personas never supply testimonials.

## Verification and stop
Check text against actual behavior, recovery paths and applicable limits. Flag missing behavior/evidence for the owner; do not invent features to make copy true. Advice writes nothing; execution writes only explicitly owned local copy documents/resources within the role's permissions. Stop when the requested copy is ready for review with remaining uncertainties stated.
