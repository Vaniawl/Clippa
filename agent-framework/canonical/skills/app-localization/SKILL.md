# App localization

Inspect actual source locales, catalog keys, extraction rules, glossary and target locales.
Use [locale-validation.md](references/locale-validation.md) for resource/layout verification.
Preserve string identity and interpolation types; localize meaning and context, not fragments.

Return assigned resource changes, translation provenance, locale/layout evidence and language
review gaps. Machine-generated translations are drafts unless appropriately reviewed. This
method grants no publishing authority and does not expand the approved language set.

## Research when needed

Use supplied/local primary sources or actually available web/docs tools permitted by the role
and task. If the active role lacks the `web` tool or access and local evidence is insufficient,
request a deep-researcher task via the orchestrator when available, or mark the claim UNKNOWN
and continue independent work. Do not infer access from a catalog or simulate source verification.
