# Creative handoff

- Tie the creative brief to audience, user value, actual available functionality and approved
  positioning. Plan a coherent icon/screenshot/preview story rather than unrelated decoration.
- Use real candidate captures for product claims. Keep source/build/device/locale and artwork
  rights/provenance; mark generated or conceptual material. Do not invent rankings/testimonials.
- Verify current placement-specific Apple dimensions, formats and marketing rules before claiming
  upload readiness. Keep editable sources and deterministic exports when the tools support them.
- Review hierarchy, legibility at placement size, contrast, dark/light contexts where applicable,
  safe areas and long localized copy. Coordinate locale assets with localization-specialist and
  metadata with the release manager; user-facing copy stays clear of framework implementation.
- Return artifact paths, dimensions, claimed behaviors and observed review results. Missing native
  capture, human brand approval or export tooling remains explicit. A local asset is not a campaign.

Sources: [marketing rules](https://developer.apple.com/app-store/marketing/guidelines/),
[screenshots and previews](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots/).
