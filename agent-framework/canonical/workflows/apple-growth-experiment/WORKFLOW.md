# Apple Growth Experiment

Roles below define responsibility, not mandatory agent calls. The coordinator may work
directly; significant/risky changes retain independent review under the delegation policy.
Use available task-relevant methods only and respect each role's write ownership.

1. Identify the decision and falsifiable hypothesis, audience, product value and actual data access. Market signals and simulated personas cannot establish demand.
2. Choose applicable product, PPO/custom-page or channel preparation. Marketing owns strategy/brief, creative owns assigned assets, localization owns assigned language resources; invoke only actual expertise gaps.
3. Before exposure specify metric/cohort/source, allocation/window, guardrails, sample rationale and interpretation. Growth analysis distinguishes App Analytics coverage, transaction reports, proceeds and attribution limits.
4. Assess actual privacy/tracking implications; instrumentation, paid tools, ad spend, account changes and outreach need separate authorized scope. An experiment plan does not install analytics or launch a campaign.
5. With supplied actual outcomes run reproducible bounded local calculations, inspect missingness/bias/confounders and practical uncertainty. Without data deliver a measurement plan and UNKNOWN result.
6. Use skeptical review only for consequential disputed claims. Report evidence, inconclusive/negative outcomes and decision options; saving a read-only analyst report is handled by an authorized writer/coordinator.

Handoff: objective, candidate/data identity, artifacts and actual commands/results, unresolved
gates with owner and next action. NOT RUN/UNKNOWN never becomes PASS by omission.
