# Prepare one specific App Store candidate

Purpose: prepare one specific app store candidate. This is the local context boundary;
[WORKFLOW.md](WORKFLOW.md) remains authoritative for detailed steps and gates.

## Inputs

| Source | Scope / why |
| --- | --- |
| User request or saved task contract | Exact app/version/build; candidate-specific checklist, metadata/assets and actual validation evidence; authorized delivery scope. |
| [Workflow](WORKFLOW.md) | Entry/exit criteria and only applicable stages |
| [Operating instructions](../../operating-instructions.md) | Mandatory execution/authority rules; read once per confirmed context |

## Process

Assess candidate gaps; prepare truthful metadata/declarations and packaging evidence; apply WORKFLOW.md gates; hand off the concrete candidate.

Load only the references required by the current step. Retain confirmed context;
when a dependency is unavailable, record the specific gap instead of inventing evidence.

## Outputs

Version-specific checklist and local submission materials at assigned paths; evidence and unresolved gates linked from the task folder.

## Human and independent gates

External upload, submission, publication and rollout retain explicit human approval. Historical starter evidence does not verify the candidate.
Advice stays in conversation unless saving is requested; existing role ownership applies.
